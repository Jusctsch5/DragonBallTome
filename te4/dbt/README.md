# Dragonball T for Tales of Maj'Eyal 1.7.6

Playable slice of Dragonball T on T-Engine 4. The ToME 3 module in `DBT/` is unchanged.

This slice covers gender birth, an Earth 1 outdoor map, melee, Uranai Baba's house, and her opening line. Chi, trainers, and the rest of the world are not in this build.

## Run

1. Install [Tales of Maj'Eyal 1.7.6](https://te4.org/download).
2. Copy this folder to `<TalesMajEyal>/game/modules/dbt`. The folder name must be `dbt`.
3. Start the game and choose Dragonball T, or launch:

```
t-engine.exe -Mdbt -uTester -n
```

`-Mdbt` loads the module, `-uTester` names the character, and `-n` starts a new game.

## Play

Birth asks for Male or Female. Gender does not change stats. You start on the grass west of the road, wearing street clothes and either tennis shoes or high heels, and carrying a kubotan.

- Move with the arrow keys or the numpad.
- Bump a wolf or a street thug to attack.
- Stand on `>` and press `<` or `>` to enter Uranai Baba's house.
- Bump Uranai Baba to hear her greeting.
- Stand on `<` and press `<` or `>` to return to the road.
- Save with Ctrl+S. Escape opens the menu.
